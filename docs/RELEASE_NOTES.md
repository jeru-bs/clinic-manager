# גרסה 1.2.0 — 2026-09-02

## שלמות נתונים וביצועים

- שמירת מפגש כותבת קודם את השורה בגיליון ורק אחר כך את אירוע היומן; כשל ביומן נכנס לתור הסנכרון ומנוסה שוב ברקע.
- כשל ברישום ליומן הפעילות אינו מבטל את הפעולה שבוצעה; מוצגת אזהרה שהפעולה לא ניתנת לביטול. רשומת שינויים גדולה מדי נשמרת בצורה מקוצרת ומסומנת "רשומה גדולה מדי לביטול".
- קריאות ל-Google מנוסות מחדש עד 4 פעמים עם המתנה הולכת וגדלה (כולל כיבוד Retry-After) בשגיאות 429, 5xx ותקלות רשת.
- הטעינה הראשונית קוראת את כל הגיליונות בבקשת batchGet אחת, ובדיקת התקינות קוראת את כל הכותרות בבקשה אחת.
- יומן הפעילות נשמר עד 400 שורות; הישנות ביותר נמחקות אוטומטית בטעינה.
- שורות ריקות (20 ומעלה בגיליון) נמחקות אוטומטית בטעינה, ובהגדרות נוסף כפתור "דחיסת גיליונות" לניקוי ידני של כל הגיליונות.
- שמירת סדרת מפגשים קבועים נכתבת בבקשת append אחת; אירועי היומן נוצרים ברקע דרך תור הסנכרון.
- מטופל חדש בשם זהה למטופל פעיל קיים נעצר עם אפשרות לפתוח את הכרטיס הקיים או לשמור בכל זאת.
- לאחר שחזור מגיבוי, דחיסה או ניקוי יומן, פעולות קודמות מסומנות כלא ניתנות לביטול, וביטול פעולה מאמת שהשורות לא השתנו מאז.

## ממשק

- יומן עם תצוגת חודש, שבוע ויום: מתג תצוגה נשמר במכשיר (ברירת מחדל: חודש במחשב, יום בטלפון), רשת שעות לפי שעות הפעילות, מפגשים כבלוקים צבעוניים לפי שעה ומשך, חגים וחריגי יומן מסומנים בעמודה, ולחיצה על משבצת פנויה מכינה מפגש חדש עם התאריך והשעה.
- מדיניות ביטולים למטופל: ללא חיוב, חיוב מלא, חצי מחיר או סכום קבוע, עם ברירת מחדל בהגדרות. סטטוס מפגש חדש "ביטול מאוחר"; אי-הגעה או ביטול מאוחר יוצרים חיוב אוטומטי שמופיע בחובות, ומעבר חזרה לסטטוס אחר מסיר אותו.
- חיפוש כללי בסרגל הצד (בטלפון: כפתור חיפוש בסרגל התחתון) לפי שם ילד, שם והטלפון של ההורה, אימייל, בית ספר, כתובת ואנשי קשר מקצועיים, עם ניווט במקלדת ופתיחת כרטיס המטופל.
- מסך הבית הפך למסך "היום": תאריך ויום בשבוע, שורת סיכום (מפגשים היום · חייבים · משימות פתוחות), המפגשים של היום לפי שעה עם תפריט פעולות (פתיחת כרטיס, עריכה או תיעוד, סימון כהתקיים, ביטול), מחר בקיפול, חובות פתוחים לפי מטופל (עד 8 + קישור לכל התשלומים) ושלוש המשימות הקרובות עם משימות באיחור תחילה.
- סימון מפגש כבוצע וביטול מפגש מהמסך הראשי עוברים דרך זרימת עבודה אחת שמעדכנת את הגיליון, מסירה את אירוע היומן בביטול וסוגרת את משימת התיעוד.
- בכל טבלה ורשימה עם כמה פעולות בשורה נשארת פעולה ראשית אחת (בוצע / שולם / קבלה הופקה / פתיחה) ושאר הפעולות עברו לתפריט ⋮; מחיקה מופיעה רק בתפריט, בלי כפתור אדום בשורה.
- תגיות סטטוס ושמות ברשימות (מפגשים, תשלומים, מסך הבית) מוצגים כתאים נפרדים עם רווח, במקום טקסט מודבק.
- רשימת המטופלים מציגה אימייל ומוסד לימודים בעמודה אחת וטלפון וסוג טיפול בעמודה השנייה, מתוך איש הקשר הראשי.
- לשונית "פרטים" בכרטיס המטופל אורגנה מחדש לכרטיסי מידע בשתי עמודות (פרטי הילד, הורים / אנשי קשר, מסגרת חינוכית, טיפול ותשלום, הערות) עם "—" לערכים ריקים ועמודה אחת במובייל.
- ליטושים למובייל: יעדי מגע של 44px במסך היום ובתפריטי השורה, ללא גלילה אופקית ברוחב 390px.

## מבנה קוד

- לוגיקה טהורה של תצוגה, תאריכים וכסף עברה ל-`docs/format-core.js`, ולוגיקת לוח הזמנים, סטטוסי מפגש והסדרות הקבועות ל-`docs/schedule-core.js`; שני הקבצים נבדקים ב-`scripts/test-format.mjs` ו-`scripts/test-schedule.mjs`.
- מטפלי הלחיצה והשליחה ב-`docs/app.js` פוצלו למפות מטפלים לפי תחום (ניווט, מטופל, מפגש, תשלום, עסק, משימה, יומן, הגדרות, קבצים), ובדיקה סטטית חדשה `scripts/check-actions.mjs` מוודאת שלכל `data-action` ו-`data-form` יש מטפל ושאין מטפלים מיותרים.

# גרסה 1.1.0 — 2026-08-19

גרסה זו מוסיפה את שלושת רכיבי העבודה הטיפולית: מטרות מובנות, שאלונים להורים ולאנשי מקצוע ודוחות טיפוליים.

## נוסף בשחרור

- לשונית מטרות בכרטיס המטופל, כולל מצב, התקדמות, יעד, הערה והיסטוריית עדכון ממפגש.
- העברה חד-פעמית וחוזרת-בטוחה של `treatment_goals` הישן למטרה בשם "מטרות קיימות", בלי למחוק את המקור.
- שתי תבניות שאלון התחלתיות הניתנות לעריכה ויצירת Google Form ייחודי לכל נמען, ללא שם מטופל בכותרת.
- פתיחת הודעת WhatsApp או מייל מוכנים, רענון תשובות מתוך המערכת וסגירת הטופס לאחר קליטת התשובה הראשונה.
- דוח אבחון, דוח התקדמות ודוח סיכום טיפול כ-Google Doc וכ-PDF בתיק המטופל.
- מסך עריכת טיוטה המבוסס על פרטי מטופל, מטרות, סיכומי מפגשים ותשובות שאלונים; הערות פנימיות ורגישות אינן נכנסות אוטומטית.
- שישה גיליונות חדשים, הכללה מלאה בגיבוי ובשחזור ותאימות לשחזור גיבויים ישנים שבהם הגיליונות החדשים טרם היו קיימים.
- בדיקות דפדפן במחשב ובמובייל למחזור השאלון, להעברת מטרות ולהפקת כל שלושת סוגי הדוחות.
- הרשאת קריאת תשובות Google Forms וחיבורי Forms ו-Docs במדיניות האבטחה של הדפדפן.

## הכנה להפעלה

- יש להפעיל את Google Forms API בפרויקט Google Cloud של מזהה ההתחברות הקיים.
- לאחר הפרסום יש להתנתק ולהתחבר מחדש כדי לאשר את ההרשאה החדשה.
- הנתונים נשארים ב-Google Sheets וב-Google Drive; תשובות, דוחות וגיבויים אינם נשמרים ב-GitHub.

## תנאי שחרור

השחרור תקין כאשר `npm.cmd run release:check` עובר במלואו, הענף `main` מסונכרן, GitHub Actions ירוק והגרסה מתוך `docs` זמינה ב-GitHub Pages.

# גרסה יציבה 1.0.0 — 2026-07-13

גרסה זו מוגדרת מוכנה לשימוש שוטף בדפדפן עבור ניהול מטופלים, מפגשים, יומן, משימות ותזכורות, תשלומים, קבצים, גיבוי ושחזור.

## נוסף בשחרור

- אירועי היומן נשמרים כאירועים פרטיים בשם כללי בלבד; נתונים ישנים ביומן עוברים ניקוי אוטומטי.
- תור סנכרון עמיד לרענון הדף עבור יומן ומסמכי מפגש, כולל ניסיון חוזר אוטומטי וידני.
- חיווי קבוע של מצב השמירה וזמן הרענון האחרון.
- העלאת קבצים בפרוטוקול מתחדש, בחלקים, עם התקדמות וביטול.
- גיליון `contacts` וכרטיסייה לניהול הורים, בני משפחה ואנשי מקצוע בכרטיס המטופל.

- Audit אחיד לפעולות עסקיות ושמירת המשתמש שביצע את הפעולה.
- Undo אטומי לכל שינויי הגיליונות של פעולה אחת, כאשר הביטול בטוח.
- תזכורת בסיסית כחלק ממשימה ותצוגת תזכורות פעילות בדשבורד.
- גיליון `audit_log` שנוצר ונבדק דרך מנגנון תקינות הנתונים הקיים.
- אימות מבנה גיבוי ומזהים כפולים לפני כתיבה כלשהי.
- גיבוי חובה לפני שחזור ו-rollback אוטומטי אם השחזור נעצר באמצע.
- בדיקות תהליך לסיווג תקלות Google, Audit/Undo, תזכורות וגיבוי/שחזור.
- הגנה מפני דריסה שקטה בעריכה מקבילה: לפני עדכון או מחיקה נבדקת גרסת הרשומה העדכנית, ובמקרה התנגשות הנתונים מתרעננים והפעולה נעצרת.
- בדיקות דפדפן אוטומטיות ב-Chromium לתצוגת מחשב ומובייל, כולל שער הכניסה, תקלת חלון Google ומסך ההגדרות.
- תהליך CI מריץ את בדיקת השחרור המלאה בכל push ל-main ובכל Pull Request.

## גבולות ידועים

- מחיקת קבצים או פעולות שכבר שינו Google Drive/Calendar מתועדות ב-Audit, אך אינן מציעות Undo חלקי שאינו יכול להחזיר את המצב החיצוני במלואו. כשל זמני במחיקת אירוע מהיומן נכנס לתור סנכרון חוזר.
- תמלול AI וחשבונית ירוקה אינם כלולים בשחרור, בהתאם להחלטת המוצר.
- מועדי ישראל נטענים אוטומטית מ-Hebcal; חופשות פרטיות וחסימות נוספות נשמרות כחריגי יומן ידניים.

## תנאי שחרור

השחרור תקין כאשר `npm.cmd run release:check` עובר במלואו, בדיקת דפדפן מקומית עוברת, אין סודות בקבצים המנוהלים, והענף `main` נקי ומסונכרן לאחר הפרסום.
